# Tourisme Wallonie

Tourisme Wallonie is a French-language tourism website created as a personal frontend portfolio project using HTML5 and CSS3.

The project presents selected destinations in Wallonia through a clear, content-focused and responsive interface.

## Live Preview

[Explore Tourisme Wallonie](https://lejeunea.github.io/tourisme-wallonie/)

## Project Overview

Tourisme Wallonie was created to practise responsive web design, visual hierarchy and the organisation of editorial content within a multi-page website.

The main page introduces three destinations in Wallonia:

- Namur
- Durbuy
- Spa

Each section combines destination imagery, descriptive content and an external link for visitors who would like to learn more.

The project also includes a dedicated contact page designed to maintain a consistent visual identity across the website.

## Main Features

- French-language tourism website

Through this project, I worked on:

- Structuring a multi-page static website
- Organising long-form editorial content

- Improving visual hierarchy and readability

## Project Status

The project is complete and available online as a frontend portfolio demonstration.

The contact form is a visual interface prototype and is not connected to a backend or email service.

This website is not affiliated with an official tourism organisation and does not provide commercial travel services.
